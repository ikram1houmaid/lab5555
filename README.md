# TP5 Java — Gestion d'une Bibliothèque

## Description
Ce projet consiste à développer une application Java pour gérer une bibliothèque en utilisant la programmation orientée objet.

## Objectifs
- Appliquer le principe d'encapsulation.
- Comprendre l'héritage et le polymorphisme.
- Redéfinir la méthode `toString()` dans chaque classe.
- Générer automatiquement les numéros d'enregistrement des documents.
- Manipuler un tableau de documents.

## Structure du projet

```text
TPBibliotheque/
├── src/
│   ├── entities/
│   │   ├── Document.java
│   │   ├── Livre.java
│   │   ├── Revue.java
│   │   ├── Dictionnaire.java
│   │   ├── Roman.java
│   │   ├── Manuel.java
│   │   └── Bibliotheque.java
│   └── test/
│       └── TestBibliotheque.java
└── README.md
```

## Fonctionnalités
- Ajouter un document.
- Afficher tous les documents.
- Supprimer un document.
- Rechercher un document par son numéro d'enregistrement.
- Afficher les auteurs des ouvrages.
- Quitter le programme à travers un menu interactif.

## Technologies utilisées
- Java
- Programmation orientée objet (POO)
- Eclipse IDE

## Exécution
1. Importer le projet dans Eclipse.
2. Vérifier la présence des packages `entities` et `test`.
3. Exécuter la classe `TestBibliotheque.java`.
4. Utiliser le menu affiché dans la console.
